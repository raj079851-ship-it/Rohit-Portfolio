## 🚀 Running Locally (Localhost)

You can run and test this portfolio locally on `http://localhost:8080` using any of the following methods:

### Option 1: Using Python (Recommended & Quickest)
If you have Python installed:
```bash
# 1. Clone the repository
git clone https://github.com/raj079851-ship-it/Rohit-Portfolio.git
cd Rohit-Portfolio

# 2. Start a local HTTP server on port 8080
python -m http.server 8080
```
Open your browser and navigate to:
👉 **[http://localhost:8080](http://localhost:8080)**

---

### Option 2: Using Node.js / `npx serve`
If you have Node.js installed:
```bash
# Run lightweight HTTP static server
npx serve -l 8080 .
```
Open your browser at:
👉 **[http://localhost:8080](http://localhost:8080)**

---

### Option 3: Using VS Code Live Server
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension by Ritwick Dey.
3. Right-click on `index.html` and select **"Open with Live Server"**.
4. Access the server (default `http://127.0.0.1:5500` or configured `http://localhost:8080`).

## 📊 Overview & Portfolio Highlights

This portfolio is an interactive, single-page application (SPA) showcasing data analysis case studies, business intelligence dashboards, and machine learning pipelines.

### Key Highlights:
- 📈 **Interactive Live BI Dashboards (Chart.js 4.x)**:
  - **Customer RFM Segmentation**: Analyzes 5 customer cohorts across 50,000+ customer records and 250,000 orders with real-time retention filters.
  - **Superstore Sales Analytics**: Interactive regional breakdown ($2.26M Sales & $226.2K Profit) across West, East, Central, and South regions.
- 🎙️ **Voice AI Assistant ("Aria & Alex")**:
  - Web Speech API integration with text-to-speech (TTS) and speech-to-text (STT) capabilities in English, Hindi, Spanish, French, and German.
- 📱 **Direct WhatsApp Inquiries**:
  - Streamlined hire/inquiry form routing directly to WhatsApp (+91 8210916738).
- 🍪 **Privacy-First Cookie & Storage Consent**:
  - Interactive cookie consent popup banner with granular preference controls.
- 📄 **Integrated PDF Resume Viewer**:
  - Modal viewer and direct download for Rohit Kumar's updated data analyst resume.
